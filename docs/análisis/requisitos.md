# Análisis de Requisitos

En esta sección se detallan los requisitos funcionales y no funcionales del sistema TaskFlow Pro.

## Requisitos Funcionales

1. **RF-01:** El sistema debe permitir a los usuarios crear, editar y eliminar tareas.
2. **RF-02:** El sistema debe permitir asignar tareas a un usuario específico.
3. **RF-03:** El sistema debe calcular el coste de una tarea o proyecto aplicando descuentos automáticos si el cliente tiene una suscripción VIP o si el volumen del proyecto supera cierto umbral.

## Requisitos No Funcionales

1. **RNF-01:** El sistema debe tener un tiempo de respuesta inferior a 200 ms para consultas estándar.
2. **RNF-02:** El código backend debe estar desarrollado en Python y estar cubierto por pruebas unitarias en un mínimo del 80%.
